# AVIN Studio (ಅವಿನ್ ಸ್ಟುಡಿಯೋ) — Photography Website

An editorial photography studio website for **AVIN Studio**, located on Car Street, Jattipalla, Sullia, Karnataka (Phone: `+91 78995 30503`).

Designed with a warm organic linen palette, editorial serif typography, clean spacing, and mobile-first responsive interactions.

---

## 🌟 Key Features

- **Warm Editorial Aesthetic**: Linen palette (`#FAF8F5`, `#F3EEE6`, `#141312`), editorial serif headings, uppercase subheadings, and native cursor experience.
- **Pure Indian Cultural Coverage**: Authentic South Indian wedding rituals (*Muhurtham*, *Jaimala*, *Havan*, *Haldi*, *Mehndi*), Baby First Birthdays, Cradle Ceremonies (*ತೊಟ್ಟಿಲು ಶಾಸ್ತ್ರ*), Maternity & Seemantha (*ಸೀಮಂತ*), Upanayana (*ಮುಂಜಿ*), Gruhapravesha (*ಗೃಹಪ್ರವೇಶ*), and Studio Matrimonial Biodata.
- **Mobile First & Responsive**: Symmetrical layouts, uncropped balanced image cards, and a sticky mobile bottom dock (`[📞 Call]` + `[💬 WhatsApp]`).
- **Interactive Editorial Lightbox**: Touch swipe gestures (swipe left/right/down to dismiss) on mobile and keyboard arrow navigation on desktop.
- **Instant Client Actions**: Direct WhatsApp booking links with pre-filled event inquiry text, one-tap calling, and Google Maps directions.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or run a local static server:

```bash
# Python
python -m http.server 3000

# Node.js (npx serve)
npx serve .
```

Visit `http://localhost:3000` in your browser.
